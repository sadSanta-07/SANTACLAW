04 YOUR TERMINAL, YOUR RULES

Ready when
you are.

Bring an OpenRouter API key, run SantaClaw locally, and choose your mode. Prefer containers? Docker is supported too.

◈ TypeScript◉ Bun◇ Docker
TERMINAL — SOURCE
# Clone the repository
git clone https://github.com/sadSanta-07/SANTACLAW.git
cd SANTACLAW

# Install and configure
bun install
export OPENROUTER_API_KEY="your_key"

# Open the workshop
bun run wakeup
TERMINAL — DOCKER
# Clone the repo, then build the image
git clone https://github.com/sadSanta-07/SANTACLAW.git
cd SANTACLAW
docker build -t santaclaw:latest .

# Run interactively with your key
docker run -it \
  -e OPENROUTER_API_KEY="your_key" \
  santaclaw:latest
↳ Add optional Telegram / web-search keys when needed.
